# Mythic Mosaic

六角の箱庭に地形を敷き、ある形ができると幻の生き物がすぐ現れる。現れた生き物が周りの土地を変え、次の形ができて連鎖する。一人用のパズル。

- 企画の正：Claude Docs「生息地づくりゲーム 企画まとめ（引き継ぎ用）」
- 計画のメモと判定の記録：[docs/plan.md](docs/plan.md)
- ふり返り：[docs/retrospective.md](docs/retrospective.md)

## 遊ぶ

https://stm28355-ux.github.io/mythic-mosaic/

完成版（1.0.0）に、ごほうびの見た目を足した 1.2.0。ブラウザだけで遊べる（PC・スマホ）。進み具合はブラウザに保存される。

- **箱庭**：草・水・砂・丘などを置いて、形ができると生き物が現れて連鎖する。「はじまりの島」と、図鑑で20匹見つけると渡れる「火の山の島」の2つ。
- **図鑑**：生き物48匹（はじまり26・火の山22）。噂（ヒント）から形を探す。
- **連鎖問題**：41問。決まった物を置いて、決めた長さの連鎖を作る。
- **スコアアタック**：8面。限られた手で点を稼ぎ、★3つを目指す。最高点の置き方は「手順を書き出す」で見られる。
- **実績**：45個。ごほうびに島の飾り（島のすみに飾られる）・称号（題名の下のリボン）・図鑑の枠（銅・銀・金・虹）。

遊び方はゲームの「遊び方」に書いてある。

## 開発

```
npm test                      # テスト
node tools/serve.mjs 5193     # 手元で http://localhost:5193/
```

ビルドはない。静的な HTML と JavaScript（ES モジュール）だけで動く。main に push すると、自動のチェック（テスト）が走り、GitHub Pages に出る。

### 中身の場所

| 場所 | 中身 |
| --- | --- |
| `src/core/` | ルール（置く・連鎖・押す）、生き物と噂、問題、スコア、実績。画面に関わらない |
| `src/data/` | 連鎖問題（`puzzles.js`）とスコアアタックの地図（`maps.js`） |
| `src/art/` | 生き物・置く物・島の飾りの絵（32×32 のドット絵を SVG で描く） |
| `src/ui/` | 画面（盤の描画、ダイアログ、エフェクト） |
| `test/` | テスト（`node --test`） |
| `docs/` | 計画と判定の記録、ふり返り、測った結果（`measure/`）、スコアアタックの最高点（`score-records.md`） |

### 道具（ゲームには出ない）

```
node tools/make-puzzles.mjs <狙い> ...          # 連鎖問題を作る
node tools/measure-score.mjs [地図id] --steps    # スコアアタックの点を測る・最高点の置き方を出す
node tools/check-creatures.mjs [all]            # 生き物の形が重ならないか・見つけやすさを確かめる
node tools/measure.mjs [all]                    # 連鎖の長さなどを測る（工程3）
```

使い方の詳しいことは、各ファイルの頭に書いてある。
